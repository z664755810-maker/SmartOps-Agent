# 智能运营助手 Agent

面向日常运营场景的 AI 助手。用户通过自然语言查询销售和库存、查看热销商品，并可组合生成图表与通知摘要。

## 项目背景

运营人员整理业务信息，通常需要在销售记录、库存台账和沟通工具之间来回切换。单纯的问答模型既不了解实时业务数据，也不应该凭空生成经营数字。

本项目将数据查询、图表整理和通知记录封装为独立业务工具，由 Agent 按请求选择工具并组合执行。数据来自 SQLite 中的演示订单，答案以查询结果为依据。

## 能力概览

- 经营概览工作台展示销售额、环比、客单价、销售走势、热销排行和库存预警，支持 7 / 30 / 90 天切换
- 商品台账支持名称搜索、分类筛选与低库存过滤
- 查询指定日期范围内的销售额、订单量和商品销量排行
- 按商品名称查询库存，并提示不存在或名称不明确的商品
- 将查询结果整理为柱状图或饼图
- 将通知内容写入演示日志，展示可扩展的通知工作流
- 后端保存对话历史、工具执行轨迹和图表结果；新建对话或点击品牌返回概览均不会清除已有会话
- 通知摘要写入演示日志，并能在概览页追溯发送渠道、时间与消息内容

## 工作流程

```text
自然语言请求 → Agent 选择业务工具 → 校验参数并查询数据
             → 根据结果继续调用工具 → 返回回答、执行记录和图表
```

每个工具只负责一类明确的业务操作；Agent 使用有限步数完成多工具任务。数据库查询由应用代码执行，模型不直接拼写或执行 SQL。

## 技术组成

Python · FastAPI · SQLAlchemy · SQLite · Function Calling · ReAct · HTML/CSS/JavaScript

## 演示范围

项目使用自动生成的模拟商品、库存与订单数据。未配置模型服务密钥时可体验本地演示模式；配置兼容工具调用的模型服务后可启用模型驱动的工具选择。通知功能只记录演示日志，不会向邮件或企业微信等外部渠道发送消息。

当前项目面向作品演示，尚未提供真实业务系统连接、用户登录或多租户权限管理。

首页的“API 文档”链接打开 FastAPI Swagger UI，可查看请求/响应 schema 并直接调试接口；它是开发者工具，不是普通业务聊天入口。
